# Búfalo Growler

Site estático em https://bufalo.pages.dev. Edite diretamente index.html com o Codex. CSS, produtos e comportamento do carrossel estão no próprio HTML. Os banners alternam a cada dois segundos, com pausa manual.

Sem painel administrativo, login, banco de dados, upload ou coleta própria de acessos/cliques. Os links da loja e imagens externas permanecem.

Publique index.html e 404.html no projeto Cloudflare Pages bufalo. Não há build nem dependências de execução. Publicação via CLI; envio ao GitHub não publica automaticamente.
